## Estado del proyecto

Antes de empezar, revisa el estado del trabajo:

- `docs/handoff.md` — estado general, decisiones ya tomadas y tareas abiertas.
- `docs/notas-sesion.md` — contexto de la última sesión (vista previa, texto
  `PENDIENTE:`, mapa).

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
